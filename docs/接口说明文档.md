# 接口说明文档
---

## 一、 核心逻辑接口

**文件**：`core/game_logic.py`  
**类名**：`GameLogic`  
**导入方式**：`from core.game_logic import GameLogic`

### 1.1 构造方法

```python
game = GameLogic()
# 自动初始化两个10×10棋盘，随机摆放3架飞机
```

### 1.2 公开方法

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `place_planes(player_id)` | player_id: 0或1 | `list[list[int]]` 10×10 | 重新随机摆放飞机 |
| `attack(player_id, row, col)` | 被攻击方, 行, 列 | `int` 0/1/2 | 攻击判定 |
| `is_player_defeated(player_id)` | player_id | `bool` | 是否全灭 |
| `get_board_state(player_id)` | player_id | `list[list[int]]` | 棋盘原始状态 |
| `get_attacked_set(player_id)` | player_id | `set` | 已攻击坐标集合 |
| `get_plane_heads(player_id)` | player_id | `list` | 机头坐标列表 |

### 1.3 常量

```python
BOARD_SIZE = 10    # 棋盘尺寸
PLANE_COUNT = 3    # 飞机数量
MISS = 0           # 未命中
HIT = 1            # 命中机身
HEADSHOT = 2       # 命中机头
```

## 二、本地对战 HTTP 接口

**文件**：`local_game.py`  
**地址**：`http://localhost:5000`

### 2.1 POST /attack

**请求**：
```json
{
  "player": 0,
  "row": 3,
  "col": 5
}
```

**响应**：
```json
{
  "success": true,
  "result": 1,
  "message": "命中机身！",
  "current_turn": 1,
  "game_over": false,
  "winner": null,
  "your_board": [[...], ...],
  "enemy_board": [[...], ...],
  "remaining_planes": { "you": 3, "enemy": 2 }
}
```

### 2.2 GET /state

**响应**：当前游戏完整状态（格式同上，不含 result/message）

### 2.3 POST /restart

**响应**：`{"success": true, "message": "游戏已重置"}`

## 三、 联机对战 WebSocket 接口

**文件**：`server.py`  
**地址**：`ws://localhost:8765`

### 3.1 客户端 → 服务端

| type | 字段 | 说明 |
|------|------|------|
| `create_room` | — | 创建新房间 |
| `join_room` | `room_id` | 加入已有房间 |
| `attack` | `room_id, row, col` | 发起攻击 |
| `restart` | `room_id` | 重新开始 |

### 3.2 服务端 → 客户端

| type | 关键字段 | 说明 |
|------|----------|------|
| `room_created` | `room_id, player` | 房间创建成功 |
| `room_joined` | `room_id, player` | 加入房间成功 |
| `game_start` | `your_board, enemy_board, current_turn` | 游戏开始 |
| `attack_result` | `result, message, game_over, your_board, enemy_board` | 攻击结果 |
| `opponent_disconnected` | `message` | 对手掉线 |
| `error` | `message` | 错误提示 |

### 3.3 enemy_board 格式说明

- `-1`：该格未被攻击过（前端显示为灰色未知格）
- `0`：已攻击→空格
- `1`：已攻击→机身
- `2`：已攻击→机头
